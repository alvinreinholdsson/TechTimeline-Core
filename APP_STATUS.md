# TechTimeline Core — app status

## Current product surface
- Build mode: target -> dependency tree
- Timeline mode: year-by-year exploration
- Compare mode: shared vs unique dependency paths
- From Nature mode: recursively follows registered dependencies toward foundational nodes
- Node inspector: type, year, relation type, confidence and source links
- Search across the node set
- Responsive layout for desktop and mobile

## Important evidence rule
The current dataset is a **research seed**, not a claim that every historical statement or dependency has been independently verified. `requires` is reserved for stronger technical dependency claims; `enables` and `alternative_support` are intentionally weaker.
